# Unit Converter App

## Project Overview
A simple Android app developed using Kotlin and XML for the Veda Technology Android Development Track (Day 24). It converts units such as kilometers to miles, kilograms to pounds, and meters to feet.

## Technologies Used
- Kotlin
- XML Layouts
- Android Studio

## Features
- Input field for value
- Spinner to select conversion type
- Accurate conversion logic
- Displays result with 2 decimal places

## How to Run
1. Clone the repository. 2. Open in Android Studio. 3. Sync Gradle. 4. Run the app.

## Outcome
The application successfully performs unit conversions and displays the correct result based on the selected type.
